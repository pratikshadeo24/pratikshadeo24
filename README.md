# About Me  
🚀 **Software & Data Engineer** passionate about building **scalable applications**, **big data pipelines**, and **cloud-native solutions**.  

💡 With hands-on experience in **AWS, GCP, and Azure**, I specialize in **backend development, data engineering, and cloud computing**. My expertise spans **React, Node.js, Express.js, Python, Spark, Hadoop, SQL, and Terraform**.  

📊 I enjoy working with **large-scale data processing**, **machine learning models**, and **distributed systems** to extract meaningful insights and drive decision-making.  

🚀 Over the years, I have worked on **end-to-end full-stack applications, real-time data pipelines, ETL workflows, and cloud-based architectures**, optimizing workflows and enhancing system performance.  

🌱 Currently expanding my knowledge in **web development, system design, and advanced data engineering** while contributing to **open-source projects**.
